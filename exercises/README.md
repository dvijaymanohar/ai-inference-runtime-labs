# Exercises

- Compare `no_grad` and `inference_mode`.
- Sweep batch size in PyTorch and ONNX Runtime.
- Export with dynamic batch and validate several batches.
- Enumerate ONNX Runtime providers and intentionally test fallback behavior.
- Compare cold-start and steady-state latency.
- Add FP16 where supported and validate numerical/quality impact.
- Hardware permitting: build a TensorRT engine and compare identical workloads.
- Document end-to-end vs kernel-only timing boundaries.
